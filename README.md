# Python Programming Examples

## Description

This repository contains Python programming examples created for learning and practice purposes. The programs cover fundamental to intermediate Python concepts with simple and easy-to-understand examples.

The repository is designed for students, beginners, and anyone interested in learning Python programming.

## Requirements

- Python 3.10 or higher

Check Python version:

```bash
python --version
```

---

## How to Run Programs

Navigate to the project directory:

```bash
cd Python-Programs
```

Run any Python file:

```bash
python filename.py
```

Example:

```bash
python match_case_example.py
```
